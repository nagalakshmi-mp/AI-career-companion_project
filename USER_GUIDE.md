# User Guide — AI Career Companion

## 1. Introduction

AI Career Companion is a career assistance application designed to help students and job seekers explore opportunities and organize their career preparation.

## 2. Getting Started

Launch the application using Streamlit or open the deployed application URL if deployment is working.

## 3. Application Features

### Dashboard
View the application's career dashboard and available summary information.

### My Resume
Access resume-related functionality and candidate profile information.

### Find Jobs
Explore available job and internship opportunities and review matching results.

### Skill Gap
Review skills that may need improvement for a selected opportunity.

### Resume Assistant
Use the resume assistance feature to support resume improvement.

### Cover Letter
Generate or prepare a cover letter for a selected opportunity.

### Interview Prep
Use the interview preparation feature to support interview practice.

### Career Assistant
Ask career-related questions through the application's assistant.

### Application Tracker
Manage and review job or internship application information.

## 4. Tips for Users

- Keep your resume and profile information accurate.
- Review job requirements before applying.
- Use skill gap results to plan further learning.
- Check generated career documents before using them.
- Verify application details and deadlines.

## 5. Troubleshooting

If a feature does not work, note the error message and report it to the project maintainer. The feature descriptions above should be checked against the running application.

## 6. Conclusion

This guide summarizes the intended use of the main AI Career Companion features. Available functionality may depend on the current application version and deployment status.
