# AI Internship Assistant

An AI-based internship assistance system that helps students create structured candidate profiles from their resumes.

## Milestone 1

The first milestone focuses on:

- Understanding internship application workflows
- Understanding RAG architecture
- Understanding multi-agent architecture
- Designing the system architecture
- Creating student profiles
- Uploading resumes
- Extracting resume text
- Using an LLM to extract structured candidate information
- Storing candidate profiles in a database

## Technology Stack

- Python
- Streamlit
- PyMuPDF
- python-docx
- OpenAI API
- SQLite
- Pandas

## Current Workflow

Student uploads resume

↓

Resume Parser

↓

Resume Text

↓

LLM Information Extraction

↓

Structured Candidate Profile

↓

SQLite Database
