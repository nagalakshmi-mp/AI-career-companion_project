# Milestone 1 Report — AI Career Companion

## 1. Project Overview

**Project Name:** AI Career Companion

AI Career Companion is an AI-powered career assistance platform designed to help students and job seekers explore internship opportunities, understand skill gaps, prepare career documents, and organize job applications.

## 2. Objectives

- Help users manage their resume and candidate profile.
- Match candidate skills with available internship opportunities.
- Identify skills that need improvement.
- Assist with resume and cover letter preparation.
- Support interview preparation and career-related questions.
- Track internship and job applications.

## 3. Technology Stack

- **Programming Language:** Python
- **Web Framework:** Streamlit
- **Data Storage:** SQLite
- **Job Data:** CSV
- **Semantic Search:** ChromaDB and Sentence Transformers
- **Documentation and Version Control:** Markdown and GitHub

## 4. Project Structure

The main project files and folders include:

- `app.py` — Streamlit application entry point.
- `requirements.txt` — Python dependencies.
- `README.md` — Project documentation.
- `AGILE_METHODOLOGY.md` — Agile development documentation.
- `data/jobs.csv` — Internship and job dataset.
- `src/` — Source code modules for the application's features.

## 5. Main Features

1. Dashboard
2. Resume and Candidate Profile Management
3. Internship and Job Search
4. Skill Gap Analysis
5. Resume Assistance
6. Cover Letter Assistance
7. Interview Preparation
8. Career Assistant
9. Application Tracker
