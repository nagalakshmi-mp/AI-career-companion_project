# Milestone 2 Report — AI Career Companion

## 1. Introduction

Milestone 2 focuses on documenting the application's main features and their intended functionality.

## 2. Feature Modules

### 2.1 Resume Management
Allows users to provide resume information for career-related assistance.

### 2.2 Job Search and Matching
Uses the available job dataset to help users explore internship opportunities and identify potentially relevant roles.

### 2.3 Skill Gap Analysis
Helps users identify skills that may need improvement for a selected job opportunity.

### 2.4 Resume and Cover Letter Assistance
Provides features to support resume improvement and cover letter preparation.

### 2.5 Interview Preparation
Supports preparation for interviews related to selected job opportunities.

### 2.6 Career Assistant
Provides career-related guidance through the application's assistant feature.

### 2.7 Application Tracker
Provides a place to manage and review internship or job application information.

## 3. Technologies Used

- Python

- SQLite
- CSV

- Sentence Transformers
