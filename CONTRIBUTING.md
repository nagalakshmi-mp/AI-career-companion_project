# Contributing to AI Career Companion

## Introduction

Thank you for your interest in contributing to AI Career Companion. Contributions that improve the code, documentation, usability, or reliability of the project are welcome.

## How to Contribute

1. Review the existing project structure and README.
2. Identify an improvement or issue.
3. Discuss significant changes with the project maintainer before starting.
4. Make changes and test them locally.
5. Submit your changes for review.

## Development Setup

1. Download or clone the repository.
2. Install dependencies listed in `requirements.txt`.
3. Run the application using:

```bash
python -m streamlit run app.py
```

## Contribution Guidelines

- Keep changes focused and understandable.
- Follow the existing Python coding style.
- Avoid uploading personal resumes, credentials, API keys, or other sensitive data.
- Update documentation when functionality changes.
- Report errors with clear steps to reproduce them.

## Testing

Test relevant features before submitting changes. Do not describe a feature as tested or fixed unless the result has been verified.

## Contact

For questions or proposed improvements, contact the project maintainer through the repository.
